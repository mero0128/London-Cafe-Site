# London Cafe & Satellite — Landing Page (Spec Project)

A bilingual (English / Amharic) landing page concept built for **London Cafe, Satellite Restaurant & Catering** — a 6-branch cafe, restaurant, bakery, and catering brand based in Addis Ababa.

🔗 **Live demo:** [london-cafe-site.vercel.app](https://london-cafe-site.vercel.app)

## About this project

This is a **speculative / unsolicited sample project**, built by Possible Technology as part of our program identifying mid-sized Addis Ababa businesses that don't yet have a landing page. It was **not commissioned** by London Cafe & Satellite, and there is no existing business relationship between Possible Technology and London Cafe. Public branding, logo, and photos were used to demonstrate what a digital presence could look like for the business, in line with standard agency "spec work" practice.

## Tech stack

- HTML5
- CSS3 (inline / embedded in `index.html`)
- Vanilla JavaScript (inline / embedded in `index.html`)
- Deployed on [Vercel](https://vercel.com)

## Features

- 🌐 **Bilingual toggle** — switch between English and Amharic content (Noto Sans Ethiopic for proper Ge'ez script rendering)
- 📱 **Mobile-first, responsive design**
- ✨ **Scroll animations** — subtle reveal/hover effects
- 🛬 **Aviation-inspired visual motif** — reflecting the "Satellite" branch naming and airport terminal location
- 📍 Multi-branch contact/location section
- 💬 Real customer review highlights pulled from public Google/Instagram/TikTok reviews

## Running locally

No build step required — it's a static site.

```bash
git clone <https://github.com/mero0128/london-cafe-site.git >
cd london-cafe-site
# then just open index.html in a browser,
# or serve it locally, e.g.:
npx serve .
```

## Content sourcing

All business details (branches, services, contact info) and customer review quotes were gathered from London Cafe & Satellite's public Google Business Profile, Instagram/TikTok (@londoncafeandcatering), and other public listings. No private data, testimonials, or claims were fabricated.
